## Como Escrever um Bom Prompt para o ChatGPT

Antes de entrar nos exemplos, vale entender o que torna um prompt realmente funcional. Não é magia — é estrutura.

**Papel** — diga ao modelo quem ele deve ser: "Você é um especialista em finanças pessoais" orienta o tom e o nível técnico da resposta.

**Contexto** — forneça o cenário: para quem é, qual o objetivo, quais restrições existem.

**Tarefa** — seja específico sobre o que você quer: redigir, resumir, listar, analisar, corrigir.

**Formato** — indique como a resposta deve ser apresentada: tópicos, tabela, parágrafo corrido, máximo de palavras.

Com esses quatro elementos, qualquer prompt fica mais preciso. Use o modelo abaixo como ponto de partida para criar os seus:

```
Você é [papel, ex.: especialista em marketing digital com 10 anos de experiência].
Contexto: [para quem é, qual o objetivo, o que já foi feito e quais restrições existem].
Tarefa: [o que você quer, começando com um verbo: escreva, resuma, compare, liste, revise].
Formato: [como a resposta deve vir: tópicos, tabela, até X palavras, tom Y].
Se faltar alguma informação importante, faça até 3 perguntas antes de responder.
```

Na prática, a diferença é grande: "faça um post sobre meu produto" gera um texto genérico; "Você é social media de uma confeitaria artesanal. Escreva uma legenda de até 80 palavras para o Instagram anunciando o bolo de pote de maracujá, com tom divertido e uma chamada para encomendar pelo WhatsApp" gera algo que você pode publicar. Os modelos abaixo já incorporam essa lógica — você só precisa preencher as lacunas.

## Prompts para Trabalho e Produtividade

Estes prompts cobrem tarefas do dia a dia corporativo: reuniões, relatórios, processos e gestão de tempo.

```
Resuma a seguinte ata de reunião em até 5 pontos de ação, indicando responsável e prazo para cada um: [cole o texto da ata aqui]
```

```
Você é um gestor experiente. Crie uma pauta objetiva para uma reunião de [duração] sobre [tema]. Inclua tempo estimado para cada item.
```

```
Reescreva o seguinte parágrafo de relatório para soar mais profissional e claro, sem alterar o sentido: [cole o parágrafo]
```

```
Crie uma lista de tarefas priorizadas para a semana com base nos seguintes projetos em andamento: [liste os projetos e suas etapas]. Use o método de priorização por impacto e urgência.
```

```
Redija uma mensagem de feedback construtivo para um colega de equipe sobre [comportamento ou situação específica]. Seja direto, respeitoso e orientado a soluções.
```

```
Elabore um plano de 30/60/90 dias para um profissional recém-contratado como [cargo] em uma empresa de [setor].
```

```
Transforme as anotações soltas abaixo em um relatório semanal de status para meu gestor, com três blocos: o que foi entregue, o que está em andamento (com % estimado) e os bloqueios que precisam de decisão dele. Seja objetivo, no máximo 200 palavras. [cole suas anotações]
```

```
Você é um consultor de processos. Descrevo abaixo uma tarefa que faço toda semana e que toma [X horas]: [descreva o passo a passo]. Aponte quais etapas posso eliminar, automatizar ou delegar e estime o tempo economizado em cada mudança.
```

```
Preciso apresentar [tema ou projeto] para [público: diretoria/cliente/equipe] em [X minutos]. Monte a estrutura dos slides (título e 3 tópicos por slide), indique onde usar um gráfico ou exemplo e termine com um slide de próximos passos.
```

```
Crie um procedimento operacional padrão (POP) para a tarefa [nome da tarefa], para que um colaborador novo consiga executá-la sozinho. Inclua objetivo, acessos necessários, passo a passo numerado e erros comuns a evitar.
```

```
Tenho estas demandas para hoje e só [X horas] livres: [liste as demandas com prazo]. Organize em ordem de execução, diga o que eu deveria adiar ou recusar e escreva uma mensagem curta e educada para negociar o prazo da que ficar de fora.
```

## Prompts para E-mail

E-mail é onde o ChatGPT mais economiza tempo no trabalho: de pedidos e cobranças a respostas difíceis que você vem adiando.

```
Você é um assistente de produtividade. Escreva um e-mail profissional para [nome do destinatário] solicitando [objetivo do e-mail]. O tom deve ser [formal/cordial/direto]. Limite a 150 palavras.
```

```
Escreva uma resposta educada e firme para o e-mail abaixo, recusando [o pedido] sem fechar a porta para uma parceria futura. No máximo 120 palavras. [cole o e-mail recebido]
```

```
Escreva um e-mail de follow-up para [nome], que não respondeu à minha mensagem sobre [assunto] enviada há [X dias]. Tom cordial, sem parecer cobrança, com uma pergunta simples que facilite a resposta.
```

```
Redija um e-mail pedindo desculpas a um cliente por [problema ocorrido, ex.: atraso na entrega]. Reconheça o erro sem se justificar demais, explique a solução e o novo prazo e ofereça [compensação, se houver].
```

```
Crie 5 opções de assunto para um e-mail sobre [tema do e-mail], com até 50 caracteres cada, claras o suficiente para o destinatário saber do que se trata antes de abrir.
```

```
Escreva um e-mail de apresentação para [cargo] da empresa [nome], oferecendo [serviço ou produto]. Mostre que pesquisei a empresa citando [detalhe específico], use no máximo 100 palavras e termine com uma pergunta de sim ou não.
```

```
Resuma a conversa de e-mails abaixo em 5 linhas: o que foi decidido, quem ficou responsável pelo quê e o que ainda está pendente. [cole a conversa]
```

```
Escreva um e-mail para meu gestor pedindo [aumento/folga/mudança de função/home office], com argumentos baseados em [resultados ou motivos]. Tom profissional e seguro, sem soar como ultimato.
```

```
Crie uma mensagem automática de ausência para o período de [datas], informando quem procurar em caso de urgência ([nome e contato]) e quando vou responder. Faça uma versão em português e outra em inglês.
```

```
Escreva um e-mail cobrando o pagamento da fatura [número], vencida em [data], no valor de [valor]. Tom cordial no primeiro parágrafo e firme no segundo, com os dados para pagamento e um novo prazo.
```

```
Escreva um e-mail convidando [público] para [evento, reunião ou webinar] em [data e horário]. Inclua o que a pessoa ganha participando, a pauta em 3 tópicos e como confirmar presença.
```

## Prompts para Estudos

![Pessoa estudando com laptop e anotações sobre IA](https://images.unsplash.com/photo-1498050108023-c5249f4df085?auto=format&fit=crop&w=1200&q=80)

Aprender com IA é mais eficaz quando você transforma o ChatGPT em um tutor personalizado. Se você está começando com IAs, o [guia completo sobre como usar o ChatGPT](/blog/como-usar-chatgpt-guia-completo-para-iniciantes) explica o básico antes de mergulhar nos prompts avançados.

Explique [conceito] como se eu tivesse 15 anos, sem jargões técnicos. Em seguida, dê um exemplo prático do dia a dia.
```

```
Crie um plano de estudos de [duração] para aprender [assunto ou habilidade] do zero. Inclua recursos gratuitos recomendados e uma meta semanal clara.
```

```
Gere 10 perguntas de múltipla escolha sobre [tema] para me ajudar a revisar antes de uma prova. Inclua a resposta correta e uma breve explicação de cada alternativa.
```

```
Você é um professor de [matéria]. Explique o conceito de [tópico específico] passo a passo, usando analogias simples e verificando minha compreensão ao final com uma pergunta.
```

```
Resuma o seguinte texto acadêmico nos principais pontos em até 300 palavras, mantendo os termos técnicos relevantes: [cole o texto]
```

```
Crie um mapa mental em formato de texto sobre [tema], com categorias principais e subcategorias, para facilitar minha memorização.
```

```
Elabore flashcards (pergunta/resposta) sobre [assunto] para revisão espaçada. Crie 10 flashcards com dificuldade progressiva.
```

```
Vou colar abaixo minha resposta para a questão [cole a questão]. Corrija como um professor exigente: aponte erros conceituais, o que faltou e dê uma nota de 0 a 10 com justificativa. [cole sua resposta]

```
Use o método socrático: em vez de me dar a resposta sobre [tema], faça uma pergunta por vez para que eu chegue sozinho à conclusão. Espere minha resposta antes de seguir.
```

```
Crie uma tabela comparando [conceito A] e [conceito B] em 5 critérios (definição, quando usar, vantagens, limitações e exemplo), para eu não confundir os dois na prova.
```

```
Tenho [X dias] até a prova de [matéria] e estes são os tópicos: [liste os tópicos]. Monte um cronograma de revisão com repetição espaçada, dizendo o que revisar em cada dia e quanto tempo dedicar.
```

## Prompts para Marketing e Redes Sociais

Marketing de conteúdo consome tempo — esses prompts aceleram a criação sem abrir mão da qualidade.

```
Você é um copywriter especializado em [nicho]. Escreva 5 opções de headline para um anúncio do produto [nome do produto], focando no benefício principal: [benefício]. Público-alvo: [descreva o público].
```

```
Crie um calendário editorial de 4 semanas para o Instagram de [tipo de negócio], com 3 posts por semana. Inclua tema, formato (carrossel/reels/estático) e chamada para ação de cada post.
```

```
Escreva uma legenda para Instagram sobre [tema do post] para uma marca de [segmento]. Tom: [descontraído/educativo/inspirador]. Inclua 10 hashtags relevantes ao final.
```

```
Você é um estrategista de conteúdo. Sugira 10 ideias de posts para o LinkedIn de um profissional de [área] que quer se posicionar como autoridade no tema [especialidade].
```

```
Crie um roteiro de 60 segundos para um Reels do Instagram apresentando [produto ou serviço]. Inclua gancho nos primeiros 3 segundos, problema, solução e CTA.
```

```
Escreva 3 variações de e-mail marketing para anunciar [lançamento/promoção/novidade] para uma lista de leads que já conhece a marca [nome da marca]. Destaque o benefício principal em cada versão.
```

```
Você é especialista em SEO. Para a palavra-chave [palavra-chave], liste 10 palavras-chave relacionadas de cauda longa, a intenção de busca de cada uma e uma ideia de título de artigo para cada.
```

```
Crie 3 personas para o público de [produto ou serviço], com nome, idade, rotina, principal dor, objeção para comprar e onde consome conteúdo. Termine com a mensagem que mais convenceria cada uma.
```

```
Escreva um anúncio de Google Ads para [produto ou serviço] com 3 títulos de até 30 caracteres e 2 descrições de até 90 caracteres, destacando [diferencial] e incluindo uma chamada para ação.
```

```
Transforme o texto abaixo em um carrossel de 8 slides para Instagram ou LinkedIn: uma capa com gancho, 6 slides com uma ideia cada (no máximo 25 palavras por slide) e um slide final com CTA. [cole o texto]
```

```
Analise os comentários e avaliações de clientes abaixo e extraia: os elogios mais frequentes, as reclamações recorrentes e 3 frases que funcionariam como prova social (para usar com autorização do cliente). [cole os comentários]
```

## Prompts para Programação

Para devs, o ChatGPT funciona melhor como par — alguém que revisa, sugere e explica, não só escreve código por você.

```
Você é um desenvolvedor sênior em [linguagem de programação]. Revise o código abaixo, aponte problemas de performance, segurança ou legibilidade e sugira melhorias com explicação: [cole o código]
```

```
Explique o que o seguinte trecho de código faz, linha por linha, em linguagem simples para alguém que está aprendendo [linguagem]: [cole o código]
```

```
Escreva uma função em [linguagem] que [descrição da funcionalidade]. Inclua comentários explicando cada etapa e um exemplo de uso no final.
```

```
Crie testes unitários para a seguinte função em [linguagem/framework de testes]. Cubra os casos: entrada válida, entrada inválida e edge cases: [cole a função]
```

```
Você é um especialista em [banco de dados]. Otimize a seguinte query SQL para melhorar a performance em uma tabela com [número] de registros, explicando cada mudança: [cole a query]
```

```
Converta o seguinte código de [linguagem A] para [linguagem B], mantendo a mesma lógica e adicionando comentários onde a sintaxe for muito diferente: [cole o código]
```

```
Liste os 5 erros mais comuns que iniciantes cometem ao trabalhar com [tecnologia/framework] e como evitar cada um deles.
```

```
Estou recebendo este erro em [linguagem/framework]: [cole a mensagem de erro]. Este é o trecho relevante: [cole o código]. Explique a causa provável, mostre a correção e diga como evitar o mesmo erro no futuro.
```

```
Escreva uma expressão regular (regex) que valide [formato, ex.: CPF com ou sem pontuação]. Explique cada parte da regex e dê 3 exemplos que passam e 3 que falham.
```

```
Escreva um README.md para o projeto abaixo, com descrição, pré-requisitos, instalação, como rodar, variáveis de ambiente e exemplos de uso. Projeto: [descreva o projeto e cole a estrutura de pastas]
```

```
Gere uma mensagem de commit no padrão Conventional Commits para as alterações abaixo, com título de até 72 caracteres e um corpo explicando o porquê da mudança. [cole o diff ou descreva as alterações]
```

## Prompts para Carreira

Do currículo à negociação de salário: prompts para quem está buscando emprego, mudando de área ou querendo crescer onde está.

```
Você é um recrutador sênior da área de [área]. Reescreva meu currículo abaixo destacando resultados mensuráveis, com verbos de ação e palavras-chave da vaga de [cargo]. Mantenha em uma página. [cole o currículo]
```

```
Compare meu currículo com a descrição da vaga abaixo e liste: requisitos que já atendo, lacunas e como apresentar experiências parecidas para cobrir essas lacunas. Currículo: [cole] Vaga: [cole a descrição]
```

```
Escreva uma carta de apresentação de até 250 palavras para a vaga de [cargo] na [empresa], conectando minha experiência em [experiência principal] com [desafio da empresa ou da vaga].
```

```
Simule uma entrevista de emprego para a vaga de [cargo]. Faça uma pergunta por vez, espere minha resposta e, ao final de cada uma, dê feedback sobre clareza, estrutura (método STAR) e o que eu poderia melhorar.
```

```
Liste as 10 perguntas mais prováveis em uma entrevista para [cargo] em [tipo de empresa] e, para cada uma, o que o entrevistador quer avaliar e um roteiro de resposta baseado na minha experiência: [resuma sua experiência].
```

```
Reescreva a seção "Sobre" do meu LinkedIn em primeira pessoa, com até 1.300 caracteres, destacando [especialidade], [resultados] e o tipo de oportunidade que procuro. Texto atual: [cole]
```

```
Recebi uma proposta de [valor] para [cargo]. A faixa de mercado que encontrei é [faixa salarial] e tenho estes diferenciais: [liste]. Escreva um roteiro para negociar o salário, com argumentos e o que responder se disserem que não há margem.
```

```
Quero migrar de [área atual] para [área desejada]. Monte um plano de transição de 6 meses com habilidades a desenvolver, como aproveitar minha experiência atual, projetos para portfólio e como me apresentar para recrutadores.
```

```
Prepare minha autoavaliação de desempenho do ciclo [período]. Com base nas entregas abaixo, destaque impacto, aprendizados e metas para o próximo ciclo, em tom profissional e sem exageros. [liste as entregas]
```

```
Escreva uma mensagem curta de networking para [nome], que trabalha como [cargo] na [empresa], pedindo 15 minutos de conversa sobre [tema]. Explique por que escolhi essa pessoa e não peça emprego diretamente.
```

```
Escreva uma carta de pedido de demissão educada para a [empresa], com último dia em [data], agradecendo pelas oportunidades e me colocando à disposição para a transição das minhas atividades.
```

## Prompts para Finanças Pessoais

Para organizar o orçamento, sair das dívidas e entender o básico de investimentos. O ChatGPT ajuda a fazer contas e comparar cenários, mas não substitui um profissional certificado em decisões de investimento.

```
Minha renda mensal líquida é [valor] e meus gastos são: [liste categoria e valor]. Organize tudo em uma tabela usando a regra 50-30-20, mostre onde estou acima do recomendado e sugira 3 cortes realistas.
```

```
Crie uma planilha de orçamento mensal, em formato de tabela que eu possa copiar para o Excel ou o Google Sheets, com as colunas categoria, valor previsto, valor gasto e diferença, indicando as fórmulas de cada coluna.
```

```
Tenho estas dívidas: [liste valor, juros mensais e parcela de cada uma]. Explique a diferença entre os métodos bola de neve e avalanche e monte um plano de quitação com cada um, mostrando qual termina antes e qual paga menos juros.
```

```
Quero juntar [valor] para [objetivo] em [prazo]. Calcule quanto preciso guardar por mês considerando um rendimento de [X% ao ano] e sugira 5 formas de aumentar a sobra mensal sem mudar radicalmente minha rotina.
```

```
Explique, como se eu fosse iniciante, a diferença entre [investimento A, ex.: Tesouro Selic] e [investimento B, ex.: CDB] em liquidez, risco, tributação e para que tipo de objetivo cada um costuma servir. Não recomende produto específico.
```

```
Estou decidindo entre pagar à vista com [X%] de desconto ou parcelar em [Y] vezes sem juros. Considerando que meu dinheiro rende [Z%] ao mês, mostre a conta e diga qual opção sai mais barata.
```

```
Analise o extrato abaixo e identifique gastos recorrentes, assinaturas que eu possa ter esquecido e categorias que cresceram. Liste em uma tabela com valor mensal e anual. [cole o extrato, sem dados sensíveis]
```

```
Monte um plano para formar uma reserva de emergência equivalente a [X meses] dos meus gastos, que somam [valor] por mês. Inclua quanto guardar por mês, onde esse dinheiro costuma ficar e o que conta como emergência.
```

```
Sou [autônomo/MEI/freelancer] com renda variável entre [valor mínimo] e [valor máximo] por mês. Crie um método simples para eu separar um "salário" fixo para mim, a reserva e os impostos a cada recebimento.
```

```
Liste 10 perguntas que eu deveria fazer antes de contratar [financiamento/consórcio/empréstimo/cartão de crédito], explicando o que cada resposta revela sobre taxas, custo efetivo total, multas e letras miúdas.
```

```
Crie um desafio de 30 dias para economizar dinheiro, com uma tarefa pequena por dia (como revisar um gasto ou cancelar uma assinatura) e uma estimativa de quanto cada uma pode poupar.
```

## Prompts para Escrita e Criatividade

```

```
Você é um editor experiente. Revise o texto a seguir quanto a clareza, coesão e gramática, explicando cada alteração: [cole o texto]
```

```
Crie um outline detalhado para um artigo de 1500 palavras sobre [tema], com H2, H3 e pontos principais de cada seção.
```

```
Escreva um parágrafo de conclusão para um artigo sobre [tema] que reforce a ideia central, traga uma reflexão final e incentive o leitor a [ação desejada].
```

```
Desenvolva um personagem para uma história de [gênero literário]. Inclua nome, idade, motivação principal, maior medo e um defeito que dificulta seus objetivos.
```

```
Reescreva o seguinte texto em um tom [mais informal/mais técnico/mais persuasivo], mantendo todas as informações originais: [cole o texto]
```

```
Crie 5 títulos alternativos para o artigo "[título atual]" com foco em CTR — use números, perguntas ou palavras de impacto.
```

```
Escreva um conto de até 500 palavras sobre [tema ou premissa], com um final surpreendente. Gênero: [ficção científica/suspense/romance/humor]. Narre em [primeira/terceira] pessoa.
```

```
Me dê 20 ideias de nome para [projeto, marca, canal ou produto] que transmitam [atributos, ex.: confiança e modernidade]. Separe em nomes descritivos, inventados e metafóricos e explique em uma linha a ideia por trás de cada um.
```

```
Escreva um poema de [número] estrofes sobre [tema] no estilo [rimado/livre/cordel/haicai] para [ocasião, ex.: aniversário da minha mãe]. Use referências a [detalhes pessoais].

## Dicas para Adaptar os Prompts

**Seja específico nos colchetes.** Quanto mais contexto você coloca nas variáveis, melhor a resposta. "Público-alvo: [mães de 30-45 anos que trabalham fora]" rende muito mais do que "[público]".

**Itere sobre a resposta.** Não descarte uma resposta ruim — peça ao ChatGPT para ajustar: "Refaça o item 3 com um tom mais direto" ou "Adicione exemplos práticos à segunda seção".

**Combine prompts.** Use o resultado de um prompt como entrada para outro. Gere o outline com um prompt e o texto completo com outro, seção por seção.

**Salve seus melhores prompts.** Crie um documento pessoal com os modelos que funcionaram bem para o seu contexto. Com o tempo, você vai construir uma biblioteca particular muito mais precisa do que qualquer lista genérica. Aliás, você também pode explorar as opções gratuitas com as [melhores IAs gratuitas](/blog/melhores-ias-gratuitas-2026) para testar esses prompts em diferentes modelos.

## Perguntas Frequentes

### Quais os melhores prompts para ChatGPT?

Os melhores prompts para ChatGPT são os que dizem ao modelo quem ele deve ser, qual é o contexto, o que exatamente fazer e em que formato responder. Na prática, os que mais economizam tempo são os de tarefas repetitivas: resumir reuniões, responder e-mails, revisar textos, montar planos de estudo e revisar código. Esta lista reúne mais de 100 deles, separados por categoria, prontos para copiar e adaptar.

### Como fazer um prompt para o ChatGPT?

Escreva em quatro partes: o papel ("Você é um recrutador sênior"), o contexto (para quem é, qual o objetivo, quais as restrições), a tarefa com um verbo claro (escreva, resuma, compare) e o formato da resposta (tópicos, tabela, número de palavras). Se faltar informação, peça ao ChatGPT para fazer perguntas antes de responder. O modelo na seção "Como escrever um bom prompt para o ChatGPT", acima, já vem com essa estrutura pronta para preencher.

### O que é um prompt de comando no ChatGPT?

No ChatGPT, "prompt" é a instrução ou mensagem que você digita para a IA — o comando que diz o que ela deve fazer. Não tem relação com o Prompt de Comando do Windows (o cmd), que serve para executar comandos no sistema operacional. No ChatGPT não existe sintaxe especial: você escreve em linguagem natural, em português mesmo, e quanto mais claro e específico for o pedido, melhor a resposta.

### Existe lista de prompts em português?

Sim. Todos os prompts desta página estão em português e funcionam no ChatGPT, que entende e responde em português sem nenhuma configuração. Para mais opções, a [biblioteca de prompts do Turbina IA](/prompts) reúne centenas de modelos gratuitos por categoria, e há coleções específicas para [marketing digital](/blog/prompts-para-marketing-digital), [programação](/blog/prompts-para-programacao) e [estudos e concursos](/blog/prompts-para-estudos-e-concursos).

### Os prompts funcionam em outros modelos além do ChatGPT?

Sim. A maioria dos prompts desta lista funciona bem no Gemini, Claude e outros modelos de linguagem modernos. Pequenos ajustes de tom podem ser necessários — o Claude, por exemplo, tende a seguir instruções de formato com mais precisão, enquanto o Gemini responde bem a contextos com dados factuais.

### Qual é o tamanho ideal de um prompt?

Não existe um número mágico, mas prompts entre 50 e 200 palavras tendem a produzir os melhores resultados para tarefas complexas. Para tarefas simples (como reescrever uma frase), prompts curtos funcionam perfeitamente. O que importa é que todos os elementos essenciais estejam presentes: papel, contexto, tarefa e formato.

### Como evitar respostas genéricas e superficiais?

O principal motivo de respostas rasas é a falta de contexto. Adicione detalhes: setor da empresa, tom de voz da marca, nível de conhecimento do público, restrições de tamanho. Outra estratégia eficaz é pedir ao modelo que faça perguntas antes de responder — isso força um alinhamento antes da execução.

### Posso usar esses prompts para fins comerciais?

Sim. As respostas geradas pelo ChatGPT podem ser usadas comercialmente de acordo com os termos de uso da OpenAI. O conteúdo gerado é de responsabilidade do usuário, então sempre revise, adapte e adicione sua perspectiva antes de publicar ou entregar para clientes.
